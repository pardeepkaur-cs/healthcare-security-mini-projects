# Healthcare Security Mini Projects

This repository contains small Python projects I developed while learning cybersecurity concepts and exploring security problems in healthcare environments.

## Projects

### 1. Hospital Login Security

A small project exploring basic login security concepts.

### 2. Password Strength Checker

A simple tool for checking password strength using common password-security rules.

### 3. Risk-Based Login Monitoring

A small demonstration of assigning risk levels to login activity using security conditions.

### 4. Suspicious Login Detection

A simple project exploring how login characteristics can be used to flag potentially unusual activity.

## Purpose

These projects are learning exercises and small demonstrations rather than production security systems.

They helped me build practical experience with Python, security concepts, and basic monitoring logic.

## Technologies

- Python
- Basic cybersecurity concepts
- Data analysis
